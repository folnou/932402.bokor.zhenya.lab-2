# Лабораторная работа №2

**Вариант:** Любитель кино и сериалов  
**Тема:** «Анализ кино и создание альтернативных сценариев»  
**Цветовая гамма:** Чёрно-золотая

## Выполненные требования

*   **Подключение стилей:** Реализовано тремя способами — внешний файл (`stylelab2.css`), inline-стиль (для заголовка) и внутренний блок `<style>` (для элемента `<aside>`).
*   **CSS переменные:** Использованы в `:root` для задания основной чёрной и акцентной золотой палитры.
*   **Позиционирование:** Продемонстрированы все типы — `static`, `relative` (обертка изображения) и `absolute` (декоративный бейдж).
*   **Сетка проектов:** Секция оформлена через `display: grid` (3 колонки). При наведении (`:hover`) появляется полупрозрачный оверлей и увеличивается шрифт заголовка.
*   **Интерактивность:** Настроены состояния `:hover`, `:active`, `:focus` (рамка кнопки) и `:visited`.
*   **Доступность:** Контрастность текста соответствует стандарту.

## Запуск

Откройте файл `lab2.html` в любом современном браузере.

## Проверка

HTML и CSS код проверен визуально на соответствие всем требованиям лабораторной работы.
